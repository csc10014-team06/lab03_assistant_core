# H2 — Extra Question, Query, and Result (nhat_dm)

## Question
**Which courses have the highest proportion of "at-risk" students (students who either failed with grade < 5.0 or do not have a recorded grade yet), and what is the failure/unassessed percentage for each course?**

### Motivation
In academic administration, identifying courses where students struggle or have pending assessments helps advisors offer timely tutoring and intervention before students fall behind.

## Query
```sql
SELECT c.code,
       c.title,
       COUNT(e.student_id) AS total_enrolled,
       SUM(CASE WHEN e.grade IS NULL OR e.grade < 5.0 THEN 1 ELSE 0 END) AS at_risk_count,
       ROUND(100.0 * SUM(CASE WHEN e.grade IS NULL OR e.grade < 5.0 THEN 1 ELSE 0 END) / COUNT(e.student_id), 1) AS at_risk_pct
FROM courses c
LEFT JOIN enrollments e ON c.code = e.course_code
GROUP BY c.code, c.title
ORDER BY at_risk_pct DESC, c.code;
```

## How It Works
1. `LEFT JOIN`: Joins `courses` with `enrollments` so all courses appear even if enrollments differ.
2. Conditional Aggregation: Uses `CASE WHEN e.grade IS NULL OR e.grade < 5.0 THEN 1 ELSE 0 END` to count students with failing or unassigned grades.
3. Percentage Calculation: Multiplies by `100.0` for float division and rounds to 1 decimal place with `ROUND(..., 1)`.
4. Grouping & Sorting: Groups by course code and title, ordering by highest at-risk rate first.
