# H2 — Extra SQL Query & Result

## Question
What is the average GPA (rounded to 2 decimal places) and number of graded courses for each student who has at least one graded course, ordered from highest average grade to lowest?

## Query
```sql
SELECT s.name,
       COUNT(e.grade) AS graded_courses,
       ROUND(AVG(e.grade), 2) AS avg_grade
FROM students s
JOIN enrollments e ON e.student_id = s.id
WHERE e.grade IS NOT NULL
GROUP BY s.id, s.name
ORDER BY avg_grade DESC, s.name;

```
