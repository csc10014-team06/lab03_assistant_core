# H2 - Backup-path share

**Question:** What percentage of the assistant's synthetic interactions used a backup (degraded) answer?

**Query:**

```sql
SELECT
    COUNT(*) AS total_responses,
    SUM(CASE WHEN degraded THEN 1 ELSE 0 END) AS fallback_responses,
    ROUND(
        100.0 * SUM(CASE WHEN degraded THEN 1 ELSE 0 END) / COUNT(*),
        1
    ) AS fallback_percent
FROM interaction;
```

**Result from 300 synthetic interactions:**

| total_responses | fallback_responses | fallback_percent |
|---:|---:|---:|
| 300 | 38 | 12.7 |

The data came from `scripts/seed.py` and contains synthetic records only. Since the team's R1 `add_feedback` implementation is still a TODO on this branch's base, I used a temporary runtime shim for feedback insertion while seeding; no team source files were changed for this result. The query itself reads only the `interaction` table.
