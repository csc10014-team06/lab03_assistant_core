# H2 — Busiest Hour

## Question

Which hour of the day is the busiest for the chatbot?

Identifying peak usage hours can help the team plan server resources and improve chatbot availability.

## SQL Query

```sql
SELECT strftime('%H', created_at) AS hour,
       COUNT(*) AS total_requests
FROM interaction
GROUP BY strftime('%H', created_at)
ORDER BY COUNT(*) DESC
LIMIT 1;
```

## Result

The query was executed on `lab05_h2_final.db`, containing 300 synthetic interactions generated using the team's migration and seed scripts.

| hour | total_requests |
|---|---:|
| 12 | 300 |

## What it tells us

- The busiest recorded hour is 12, with 300 interactions.
- All interactions occurred within the same hour because the database was populated using a seed script.
- This synthetic result demonstrates that the query works, but real interaction data is needed to identify actual peak usage hours.
- The query uses timestamps only and does not require raw user messages.
