# Homework H2 — One Question About the Assistant (`truyen_lp`)

## Question

**How does answer quality (normal vs. degraded vs. unresolved) relate to user feedback (`thumbs_up` vs. `thumbs_down` and positive rate %)?**

Why this matters: comparing `resolved` and `degraded` flags against `feedback.rating` reveals whether fallback/backup responses or unresolved answers drive negative feedback, helping the team prioritize improvements.

## SQL Query

```sql
SELECT
    i.resolved,
    i.degraded,
    COUNT(f.id) AS total_feedback,
    SUM(CASE WHEN f.rating = 1 THEN 1 ELSE 0 END) AS thumbs_up,
    SUM(CASE WHEN f.rating = -1 THEN 1 ELSE 0 END) AS thumbs_down,
    ROUND(100.0 * SUM(CASE WHEN f.rating = 1 THEN 1 ELSE 0 END) / COUNT(f.id), 1) AS thumbs_up_pct
FROM interaction i
JOIN feedback f ON f.request_id = i.request_id
GROUP BY i.resolved, i.degraded
ORDER BY i.resolved DESC, i.degraded ASC;
```

## Result (from 300 seeded interactions in `assistant.db`)

```text
resolved | degraded | total_feedback | thumbs_up | thumbs_down | thumbs_up_pct
---------+----------+----------------+-----------+-------------+--------------
1        | 0        | 70             | 61        | 9           | 87.1
1        | 1        | 18             | 0         | 18          | 0.0
0        | 0        | 8              | 0         | 8           | 0.0
```

**Takeaway:** Normal resolved interactions (`resolved = 1, degraded = 0`) received **87.1%** positive feedback (`61/70`), whereas degraded (`resolved = 1, degraded = 1`) and unresolved (`resolved = 0, degraded = 0`) responses received **0.0%** positive feedback (`0/18` and `0/8`).
